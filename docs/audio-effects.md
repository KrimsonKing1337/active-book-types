# Декларативное аудио

В `book.json` аудио хранится на уровне книги в массиве `audioEffects`.
`AudioEffect` описывает один звук. `EffectLifetime` задаёт область действия через
ID страницы или через один или несколько позиционных интервалов.
ID уникален во всей книге. По нему эффект доступен через `book.hooks.useAudioController(id)`,
пока он активен. Несколько ID могут использовать один файл и воспроизводиться независимо.

| Поле | Значение |
| --- | --- |
| `id` | Непустой уникальный ID |
| `src` | Путь к файлу в `assets/`, HTTP(S) или аудио data URL |
| `lifetime` | `{ type: 'page', page: 'page-id' }` или `{ type: 'range', range: [{ from: 2, to: 4 }] }` |
| `type` | Категория микшера `bg`, `music` или `sfx`. По умолчанию `sfx` |
| `relativeVolume` | Относительная громкость от 0 до 100. По умолчанию 100 |
| `loop` | Повтор воспроизведения. По умолчанию `false` |
| `playOnLoad` | Один автоматический запуск на активацию. По умолчанию `false` |
| `delay` | Задержка автозапуска от начала активации, в миллисекундах. По умолчанию 0 |
| `stopBy` | Момент начала автоматической остановки от начала активации, в миллисекундах. По умолчанию 0, дедлайн отключён |
| `fadeIn` | Плавное появление при автозапуске. По умолчанию `false` |
| `fadeOut` | Затухание при выходе из области действия и остановке по `stopBy`. По умолчанию `false` |
| `waitTillTheEnd` | При выходе до дедлайна проиграть текущую итерацию. По умолчанию `false` |
| `screamer` | Флаг режима скримера для аудиотранспорта. По умолчанию `false` |
| `format` | Необязательный список подсказок о формате. По умолчанию транспорт определяет формат по источнику |

Позиции диапазона начинаются с 1, обе границы включены. Перестановка страниц
сохраняет ссылку на ID у постраничного эффекта и сохраняет числа у диапазонов.
Builder проверяет ссылки и границы и преобразует ID страницы в позицию.
Ядро объединяет соседние и перекрывающиеся интервалы перед вычислением идентичности.

```json
{
  "audioEffects": [
    {
      "id": "door",
      "src": "assets/door.wav",
      "lifetime": { "type": "page", "page": "entrance" },
      "playOnLoad": true
    },
    {
      "id": "rain",
      "src": "assets/rain.ogg",
      "lifetime": { "type": "range", "range": [{ "from": 2, "to": 4 }, { "from": 8, "to": 9 }] },
      "type": "bg",
      "loop": true,
      "playOnLoad": true,
      "fadeIn": true,
      "fadeOut": true
    }
  ]
}
```

Временные поля отсчитываются от `t₀`. Он совпадает с первым фактическим раскрытием страницы в области
действия эффекта. Переход внутри диапазона и восстановление экземпляра при
быстром возврате сохраняют `t₀`. Новый экземпляр получает новую временную шкалу.

Диапазоны поддерживают движок и сборщик. Полноценное управление ими в интерфейсе
редактора отложено до отдельной работы над моделью эффектов произведения.
