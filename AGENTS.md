# ActiveBook types

Пакет содержит только декларации типов. Не добавляйте runtime-код.
Проверки: `npm run typecheck`, `npm test`, `npm run test:bundler`.
Сохраняйте тесты контрактов NodeNext и Bundler и точность optional-полей.
